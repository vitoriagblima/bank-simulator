# Guias de Contribuição — Bank Simulator

Obrigado pelo interesse em contribuir com este projeto! Como este é um repositório voltado ao estudo prático e incremental de Java e Programação Orientada a Objetos (POO), toda contribuição, sugestão ou correção é muito bem-vinda.

---

## Como você pode contribuir?

1. **Reportando Bugs / Problemas:**
   - Abra uma *Issue* detalhando o erro encontrado.
   - Inclua os passos para reproduzir o problema e, se possível, a mensagem de erro/logs.

2. **Sugerindo Melhorias:**
   - Ideias de refatoração, melhoria em regras de negócio (ex: limites, taxas) ou novas funcionalidades são super válidas.

3. **Enviando código (Pull Requests):**
   - Faça um **Fork** deste repositório.
   - Faça as alterações necessárias no seu código.
   - Abra um **Pull Request** apontando para a branch `main` deste repositório.

---

## Padrões do Projeto

- **Linguagem:** Java 11 ou superior.
- **Estrutura:** Mantenha a separação de pacotes (`application` para entrada no console/Main e `entities` para o modelo de domínio).
- **Boas Práticas:** Respeite o encapsulamento, o uso correto dos modificadores de acesso e a legibilidade do código.
