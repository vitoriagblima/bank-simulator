# Política de Segurança

## Projeto de Estudo

Este repositório é um projeto educacional/simulador e não deve ser utilizado em ambientes de produção real nem para processar dados financeiros reais.

## Reportando uma Vulnerabilidade

Caso encontre alguma falha de segurança, exposição acidental de dados ou problema crítico de lógica na aplicação:

1. **Não** abra uma *Issue* pública detalhando a vulnerabilidade.
2. Utilize a aba **Security > Advisories** do repositório no GitHub (quando habilitada) ou entre em contato diretamente com a mantenedora do repositório de forma privada.
3. Descreva os passos necessários para reproduzir o comportamento encontrado.

Agradecemos por ajudar a manter o projeto seguro e bem estruturado!
