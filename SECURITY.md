# Política de Segurança

## Projetos de Estudo

Este repositório é um projeto educacional/simulador e não deve ser utilizado em ambientes de produção real. 

## Reportando uma Vulnerabilidade

Caso encontre alguma falha de segurança, exposição acidental de dados de teste ou problema de lógica na aplicação:

1. **Não** abra uma issue pública detalhando a vulnerabilidade crítica.
2. Entre em contato diretamente com os mantenedores do repositório enviando uma mensagem privada ou e-mail.
3. Descreva os passos necessários para reproduzir a falha.

Agradecemos por ajudar a manter o projeto seguro e bem estruturado!
